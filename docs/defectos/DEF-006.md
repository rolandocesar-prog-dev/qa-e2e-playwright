## Pasos para reproducirlo

1. Iniciar sesión en https://www.saucedemo.com con `problem_user` / `secret_sauce`.
2. Agregar «Sauce Labs Backpack», abrir el carrito y pulsar «Checkout».
3. Escribir «Pérez» en «Last Name».

## Resultado esperado

«Last Name» muestra «Pérez».

## Resultado obtenido

«Last Name» queda vacío y el texto reemplaza el contenido de «First Name». Al continuar aparece «Error: Last Name is required».
