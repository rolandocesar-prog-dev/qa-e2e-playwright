## Pasos para reproducirlo

1. Iniciar sesión en https://www.saucedemo.com con `error_user` / `secret_sauce`.
2. Elegir «Name (Z to A)» en el selector de orden.

## Resultado esperado

Los productos se reordenan de Z a A.

## Resultado obtenido

Aparece el diálogo «Sorting is broken! This error has been reported to Backtrace.» y la lista no cambia.

## Evidencia

- La prueba está marcada con `test.fail()`: pasa mientras el defecto exista y falla el día que
  se corrija. Cada ejecución guarda una captura y el _trace_ en el reporte HTML del CI.
- Con `standard_user`, la misma prueba cumple el resultado esperado (control).
