## Pasos para reproducirlo

1. Iniciar sesión en https://www.saucedemo.com con `error_user` / `secret_sauce`.
2. Agregar «Sauce Labs Backpack», abrir el carrito y pulsar «Checkout».
3. Completar nombre y código postal y pulsar «Continue» (llega al resumen por DEF-012).
4. Pulsar «Finish».

## Resultado esperado

Se muestra «Thank you for your order!» y el carrito queda vacío.

## Resultado obtenido

La página no cambia y lanza un error de JavaScript (`… is not a function`).

  se corrija. Cada ejecución guarda una captura y el _trace_ en el reporte HTML del CI.
